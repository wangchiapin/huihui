# 輔導牌卡

> 輔導談話用的三種牌卡小工具：情境抽卡、接句子、價值觀排序。

- **形式：** 單一檔案 `index.html`，直接用 GitHub Pages 開啟，不需要安裝。
- **網址：** https://wangchiapin.github.io/huihui/
- **Firebase：** 不使用。頁面底下寫明「不會儲存或上傳任何內容，關掉頁面就沒有了」，沒有登入、沒有排行榜、沒有遊玩紀錄。
- **狀態：** 使用中（2026-10-22 加入三種牌卡）

## 功能
1. **情境抽卡**：隨機抽一個情境（人際、感情、手機網路、升學生涯、家庭、情緒壓力、校園生活，共 28 張），一起聊「如果是你，會怎麼做？」，沒有標準答案。可以只抽某一類。
2. **接句子**：抽到半句話，接著說完（23 張），不想說可以換一張。依深淺分三級（輕鬆暖身、一般、比較深入），可以只抽某一級。
3. **價值觀排序**：從 20 張價值觀卡裡依序選出現在最重要的 5 張，選完會列出排序與三個可以討論的問題；再點一次可取消，「全部重來」清空。

右上角「投影模式」會把字放大，方便投影到螢幕上給大家看。

## 修改內容
牌卡文字都在 `index.html` 的 `<script>` 裡：情境 `SCENES`（每張有分類 `c` 與內容 `t`）、接句子 `SENTS`（每張有深淺等級 `l` 與內容 `t`）、價值觀 `VALUES`（每張有名稱與一句說明），情境分類名稱在 `SCENE_CATS`，接句子的深淺等級（`l`＝1～3）名稱在 `SENT_CATS`。直接改文字就好，不用動其他地方。
